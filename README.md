# KaiGram — обновления

Канал обновлений Android-клиента KaiGram. Здесь нет исходного кода приложения.

Готовые APK публикуются в [Releases](../../releases/latest). Файл `update.json` используется кнопкой «Проверить обновления» в приложении. Перед установкой KaiGram проверяет SHA-256 файла, имя пакета, версию и подпись APK.

Исходный код и ключ подписи не размещаются в этом репозитории.
